# VAR LP 追加セクション｜実装用データ納品依頼

> 💡 **このページについて**
> VAR LPへの追加セクション実装用に、デザイナーへ依頼する納品仕様です。
> 追加セクションはすべて **画像1枚ずつ** で実装します。

---

## 依頼概要

| 項目 | 内容 |
| --- | --- |
| 対象 | VAR（GUINOT フェイシャルマシン）ランディングページ |
| 作業内容 | **追加セクションのみ** の実装用データ納品 |
| 実装方式 | セクションごとに画像1枚を貼り付け |
| メインビジュアル | **作り直し・納品不要** |
| 既存セクション | **作り直し・納品不要** |

> ⚠️ Figmaの全体整理や開発向けの細かい設定は **不要** です。
> 下記の必須納品物が揃えば実装可能です。

---

## 必須納品物

### 1. セクション画像の書き出し

各 **追加セクション** を、以下の条件で書き出してください。

| 項目 | 指定内容 |
| --- | --- |
| 対象 | 追加セクションのみ |
| 幅 | **860px**（実装表示幅430pxの2倍） |
| 形式 | **WebP** と **JPG** の2形式 |
| 画質 | WebP：80〜85%／JPG：85%程度 |
| ファイルサイズ目安 | 1セクションあたり WebP **200KB以下** |
| ファイル名 | `add_01_セクション名`（連番 + 英語名） |
| 納品方法 | ZIP または Google Drive 等 |

**ファイル名の例**

```
add_01_salon_voice.webp
add_01_salon_voice.jpg
add_02_case_study.webp
add_02_case_study.jpg
```

---

### 2. セクション一覧表

スプレッドシート、Excel、またはこのNotionページ内の表で共有してください。

| # | セクション名（日本語） | ファイル名 | 既存LP上の挿入位置 | alt用テキスト（1行） | 備考 |
| --- | --- | --- | --- | --- | --- |
| add_01 | （例）導入サロンの声 | add_01_salon_voice | 「症例」セクションの後 | 導入サロン様の声 | |
| add_02 | | add_02_xxx | | | |
| add_03 | | add_03_xxx | | | |

**挿入位置の書き方例（既存セクション名で指定）**

- 「メインビジュアル」の後
- 「症例（RESULTS）」の後
- 「5つの理由」の前
- 「価格（PRICING）」の前

> 💡 挿入位置が未定の場合は、実装前に開発側で調整します。可能であればご提案ください。

---

### 3. alt用テキスト

各セクション画像に設定する **代替テキスト（1行）** を、一覧表に記載してください。

- 画像内の主要な見出し・内容が分かる短文でOK
- 例：「導入サロン様の声」「VAR導入後の売上アップ事例」

## 不要な作業

以下は **依頼しません**。対応不要です。

- [ ] メインビジュアル（MV）の書き出し
- [ ] 既存セクションの作り直し・Figma整理
- [ ] サイト全体の Variables / Styles 整備
- [ ] セクションごとのFrame命名の統一（全体）
- [ ] Dev Mode向けの詳細スペック整備
- [ ] HTML/CSS用のコンポーネント分解

---

## デザイン条件

| 項目 | 内容 |
| --- | --- |
| 表示幅 | **430px** 基準（スマートフォン向けLP） |
| トーン | 既存VAR LPに合わせたデザイン |
| フォント参考 | 日本語：Noto Sans JP／英語：Montserrat |
| テキスト | Figma上は **アウトライン化しない** |

> ⚠️ 375px等で作成している場合は、860px書き出し時に **430px表示で自然に見えるか** ご確認ください。

---

## 避けてほしい納品形式

| 形式 | 理由 |
| --- | --- |
| PDF1枚のみ | セクション分割・圧縮が困難 |
| 縦に長い1枚画像のみ | 境界が不明確 |
| 画面キャプチャ（スクショ）のみ | 画質・解像度が不安定 |
| 430px幅のままの書き出し | Retina用860pxが望ましい |

---

## 納品チェックリスト

納品前にご確認ください。

- [ ] 追加セクションのみ書き出している（MV・既存セクションは含まない）
- [ ] 各セクションが **860px幅** で書き出されている
- [ ] **WebP + JPG** の両方がある
- [ ] ファイル名が `add_01_xxx` 形式で統一されている
- [ ] セクション一覧表（挿入位置・alt付き）がある
- [ ] 1セクションあたり WebP **200KB以下** を目安に圧縮されている
- [ ] 430px表示で、文字や画像がぼやけていない

---

## 納品後の流れ（参考）

1. いただいた画像をLPの `images/` フォルダに配置
2. 一覧表の挿入位置に従い、既存LPへセクションを追加
3. 430px幅で表示確認
4. 問題があれば該当セクションのみ修正依頼

## 開発側から共有するもの（推奨）

依頼とあわせて、以下を共有すると挿入位置のすり合わせがスムーズです。

- 既存LPのURL、または430px幅のスクショ
- 追加セクションの想定挿入位置（未定なら「デザイン順のまま」でも可）

## 補足

今回の追加セクションは、すべて **画像1枚ずつ** で実装します。

**860pxでの書き出し画像 + セクション一覧 + altテキスト** が揃えば、スムーズに反映できます。
