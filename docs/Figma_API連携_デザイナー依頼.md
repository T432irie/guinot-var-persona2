> Figma の **Personal Access Token（個人アクセストークン）** を1つ発行していただくだけで完了します。所要時間は約5分です。

---

## 何のため？

開発側で **Figma API** を使い、デザインの**テキスト・数値・レイアウト・画像**を正確に取得して LP に実装します。
画像書き出しの手作業なしで、デザインの内容をそのまま反映できるようになります。

そのために、デザインファイルを**読み取る権限を持つトークン**が必要です。

## トークンの発行手順

1. PC版 Figma または [figma.com](https://www.figma.com) にログイン
2. 画面右上の**アカウントアイコン** → **Settings（設定）** を開く
3. 左メニューまたはタブの **Security（セキュリティ）** を選択
4. **Personal access tokens** の項目で **「Generate new token（新しいトークンを生成）」** をクリック
5. 以下を設定して発行

| 項目 | 設定内容 |
| --- | --- |
| Token name（名前） | `GUINOT_LP 開発連携`（任意の分かる名前でOK） |
| Expiration（有効期限） | `90 days` など任意（無期限も可） |
| **Scopes（権限）** | **File content … Read only** に設定（※重要） |

> 💡 権限は **「File content（ファイル内容）」の Read only（読み取りのみ）** だけで十分です。
> 他の権限（書き込み・コメント・Webhook 等）は**不要**です。**編集や削除はできません。**

6. 生成された **`figd_` から始まる文字列**をコピー
   - ⚠️ **この画面を閉じると二度と表示されません。** 必ずその場でコピーしてください。

## 共有方法

発行したトークン（`figd_xxxxxxxx...`）を、開発担当へ共有してください。

- セキュリティのため、できれば**チャット等の安全な手段**でお送りください
- トークンは**いつでも Figma の同じ画面から失効（Revoke）**できます。連携作業が終われば削除いただいてもOKです

## よくあるご質問

**Q. トークンを渡すと、私のアカウントの他のファイルも見られますか？**
A. トークンは発行者アカウントが**閲覧可能なファイルを読み取れる**仕様です。気になる場合は、下記「別案」をご利用ください。

**Q. 編集や削除をされませんか？**
A. されません。権限を **Read only（読み取り専用）** にしていただくため、内容の取得のみ可能です。

**Q. 後から無効化できますか？**
A. はい。Figma → Settings → Security → Personal access tokens から、いつでも該当トークンを Revoke（失効）できます。

開発担当が**自分のアカウントでトークンを発行**して進めます（デザイナー様のトークン共有は不要）。
